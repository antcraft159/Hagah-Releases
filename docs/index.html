설치하는 방법

  1. 위 버튼으로 Hagah-win-Setup.exe 를 내려받아 실행하세요.
  2. 파란 "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행 을 누르세요.
  3. 설치가 끝나면 Hagah 가 바로 열려요. 바탕화면과 시작 메뉴에도 생겨요.

한 번 설치하면 새 버전이 나올 때 앱이 알아서 업데이트해요. 이 페이지에 다시 올 필요는 없어요.

"PC 보호" 창이 왜 뜨나요?

개인이 만든 앱이라 마이크로소프트의 유료 코드 서명이 아직 없어서 그래요. 이 페이지에서 받은 파일이라면 안심하고 실행하셔도 돼요.
