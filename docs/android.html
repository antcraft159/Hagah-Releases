Android 설치 방법

Hagah는 플레이스토어가 아니라 이 홈페이지에서 내려받는 앱입니다. 처음 한 번만 휴대폰이 몇 번 확인을 묻는데, 아래 순서대로 누르시면 됩니다.

최신판 확인 중…

파일이 70MB쯤이라 와이파이에서 받는 것이 좋습니다.

준비할 것

  • 안드로이드 휴대폰 (갤럭시 등, Android 6.0 이상)
  • 휴대폰 인터넷 앱: Chrome 또는 삼성 인터넷
  • 와이파이

1단계 · 내려받기

휴대폰으로 이 페이지를 열어 주세요.

  1. 위의 Android용 내려받기 단추를 누릅니다.
  2. ‘이 파일은 기기에 해를 끼칠 수 있습니다’ 같은 창이 뜨면 그래도 다운로드를 누릅니다. 플레이스토어 밖에서 받는 앱에는 다 뜨는 안내입니다. 걱정하지 않으셔도 됩니다.

2단계 · 설치 허락하기

처음 한 번만 합니다.

  1. 다 받아지면 화면 맨 위를 아래로 내려 알림창을 열고, Hagah-android.apk를 누릅니다.
  2. ‘출처를 알 수 없는 앱’이라는 창이 뜨면 설정을 누릅니다.
  3. 이 출처 허용을 켜고, 휴대폰의 뒤로 가기를 누릅니다.

3단계 · 설치하기

  1. 설치를 누릅니다.
  2. ‘Play 프로텍트’ 창이 뜨면 세부정보 더보기 → 무시하고 설치를 누릅니다. Hagah는 Google에 등록된 개발자가 서명한 앱입니다.
  3. 설치가 끝나면 열기를 누릅니다.

끝입니다. 이제 Hagah를 쓰시면 됩니다.

앱을 지우기 전에 꼭 백업하세요

앱을 지우면 앱 안에 써 둔 메모도 함께 지워집니다.

지우기 전에 앱의 설정 → 백업으로 백업 파일을 만들어 카카오톡 ‘나와의 채팅’이나 구글 드라이브로 보내 두세요.

이럴 땐 이렇게 하세요

3번 창이 안 뜨고 설치가 안 돼요 (삼성 갤럭시)

설정 → 애플리케이션 → Chrome(또는 삼성 인터넷) → 출처를 알 수 없는 앱 설치에서 허용으로 바꾼 다음, 2단계부터 다시 해 주세요.

창에 적힌 글자가 위와 조금 달라요

휴대폰마다 문구가 조금씩 다릅니다. ‘허용’ · ‘설치’ · ‘그래도’처럼 비슷한 뜻의 단추를 누르시면 됩니다.

새 판이 나오면 어떻게 하나요?

앱을 열면 새 판이 있다고 알려 줍니다. 업데이트를 누르시면 됩니다. 처음 한 번은 ‘Hagah의 앱 설치 허용’을 켜 달라고 하는데, 2단계처럼 켜 주세요. 써 둔 메모는 그대로 남습니다.

내려받은 apk 파일은 지워도 되나요?

네. 설치가 끝나면 내 파일 → 다운로드의 Hagah-android.apk는 지워도 됩니다. 앱은 그대로 있습니다.

Windows · Mac 판은 Hagah 홈에서 받을 수 있습니다.
